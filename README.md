# GradeMaster — CGPA & SGPA Calculator

My friends and I had a problem converting SGPA, CGPA, etc., so I made this simple app. Period.

## Features
- **Grade Calculator**: Calculate your SGPA/GPA for a single semester.
- **CGPA Combiner**: Combine multiple saved semesters to determine your overall cumulative GPA.
- **Percentage Converter**: Instantly convert your CGPA or SGPA into its equivalent percentage.
- **History**: Automatically saves your calculations so you don't lose track of your past semesters.

## How to use locally
Just clone this repo and open `index.html` in your browser. No setup required!
```bash
git clone https://github.com/Rutwik-M/gpa-now.git
cd gpa-now
```
